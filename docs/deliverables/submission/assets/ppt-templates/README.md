# PPT 模板素材

这些文件是本项目当前可直接参考的本地 PPT 版式素材，来源于 Codex `frontend-slides` 的 Bold Design Pack。仓库内保存的是模板的设计说明与预览规则，便于制作时统一调用；最终汇报页仍使用清先住的产品截图、真实 3D 场景和已登记素材。

## 推荐组合

| 模板 | 适用页 | 使用方式 |
|---|---|---|
| `soft-editorial` | 封面、人物故事、价值收束 | 暖纸张、家居杂志感；中文标题使用 Noto Serif SC 或系统中文衬线字体 |
| `emerald-editorial` | 2D 户型、3D 空间、环境场景 | 深绿空间底色与暖白内容区，适合昼夜切换和空间大图 |
| `blue-professional` | Agent 架构、实验室矩阵、证据页 | 清晰、可信，适合流程图、指标和技术结构 |
| `signal` | 失败诊断、风险点、章节转场 | 深色简报感，使用金色规则线强调任务状态和时间戳 |

推荐版式路线：`soft-editorial` 开场 → `emerald-editorial` 空间与人物 → `blue-professional` 技术与实验室 → `signal` 失败/修复 → `soft-editorial` 价值收束。

## 使用边界

- 模板设计说明用于版式和色彩参考，产品证据来自本仓库的 Web 录屏、户型图、Lux3D/IKEA 资产和仿真结果。
- 模板内的示例文案、图片和字体授权不自动覆盖本项目；实际使用时为字体、图片和图标登记来源。
- PPT 画布保持 16:9；移动端 Web 画面作为手机窗口或纵向插图嵌入，不将 PPT 页面改成移动端比例。
