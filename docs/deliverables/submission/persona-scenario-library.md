# 清先住 · 人物与情景素材库

| 项 | 内容 |
|---|---|
| 文档类型 | PPT、视频和产品展示的角色/情景素材设计 |
| 状态 | 展示素材初版；现场主 Demo 采用一条稳定路径 |
| 日期 | 2026-10-31 |

## 1. 设计目标

清先住的空间判断需要落到具体的人、具体的任务和具体的时间条件。人物卡提供行为目标，情景卡提供环境条件；同一户型可以在不同人物和情景下重复测试，形成实验室模式中的可比样本。

人物展示强调自主生活、选择权和任务完成过程。情景展示强调空间条件变化带来的可测影响，昼夜和应急状态均使用真实或明确标注的预计算结果。

## 2. 人物卡

| 人物卡 | 主要任务 | 关键变量 | 推荐画面 | PPT/视频用途 |
|---|---|---|---|---|
| 轮椅使用者 | 从卧室到卫生间、床边转身、取用衣物 | 轮椅外廓、转弯半径、座面高度、触达范围 | 3D 跟随视角 + 路径与余量 | 现场主 Demo |
| 助行器使用者 | 玄关放置助行器、进入客厅、坐下和起身 | 助行器外廓、步行速度、停靠空间 | 2D 任务卡 + 3D 低速行动 | 人物扩展示例 |
| 视障住户 | 从卧室到卫生间、识别门和目标物 | 光照、连续边界、声音/触觉提示区域 | 深色路径 + 非颜色标签 + 3D 近景 | 无障碍关怀页 |
| 老年住户 | 夜间起床、到卫生间、返回床边 | 步速、照度、扶手、休息点 | 夜间暖光 3D 镜头 + 时间线 | 夜间情景 |
| 家属/照护者 | 与住户共同通行、放置物品、协助转向 | 两人占用宽度、等待位置、交互距离 | 双人物 3D 截图 + 任务节点 | 家庭决策页 |

首个稳定 Demo 使用轮椅使用者；其他人物先以统一视觉模板和预计算案例出现，再按真实可运行能力扩展为交互角色。

## 3. 情景卡

### 3.1 白天：日常生活

空间条件：自然光或常规室内照明，家具按正常使用状态摆放，门扇和抽屉处于日常状态。

任务示例：进入卧室、床边转身、取衣物、回到客厅。画面使用暖白背景、青绿通行路径和木色家具，适合视频主线的第一次失败与修复。

### 3.2 夜间：低照度与方向确认

空间条件：照度降低，局部夜灯开启，屏幕保留高对比度路径和文字标签。测试重点是连续路径、门口识别、床侧余量和返回路线。

任务示例：夜间起床 → 到卫生间 → 返回床边。3D 画面使用蓝灰环境与暖色夜灯，2D 画面保留照度、路径和任务状态字段。没有实际照度数据时，标注为“情景演示”，不填写推测数值。

### 3.3 应急：电力中断或通道受阻

空间条件：主照明关闭，保留应急光；指定一条通道出现可控障碍或家具倒伏占用。测试重点是替代路线、出口可达性、转向余量和家庭成员会合位置。

任务示例：从卧室到出口 → 绕过受阻点 → 在玄关会合。画面使用深色底、琥珀色应急路径和明确的障碍轮廓；产品当前未实现的烟雾、火焰、结构破坏效果只作为概念分镜，正式展示使用可复现的“通道受阻”状态。

## 4. 2D–3D 表达规则

| 信息 | 2D 表达 | 3D 表达 |
|---|---|---|
| 人物差异 | 人物卡、任务标签、变量清单 | 外廓、速度、姿态和行动轨迹 |
| 昼夜差异 | 时间标签、照明状态、路径图例 | 环境光、夜灯、阴影和镜头曝光 |
| 应急差异 | 障碍位置、替代路线、状态标签 | 受阻物体、绕行、会合与出口视角 |
| 结果差异 | 通过/受阻、任务节点、证据卡 | 路径断点、碰撞点、复测动画 |

颜色不是唯一信息来源：状态同时使用文字、轮廓、图标和纹理。视频字幕与 PPT 标签保持“白天 / 夜间 / 应急”三种明确命名。

## 5. PPT 页面建议

在现有 10 页结构中增加一页“同一空间，不同生活条件”，将原实验室模式页拆成两页：

1. **人物与情景矩阵**：左侧展示 5 张人物卡，顶部展示白天/夜间/应急三种情景；中央用 2D 矩阵说明测试组合。
2. **具身任务对比**：选择轮椅使用者在白天和夜间的同一条任务路径，左侧 2D 状态，右侧上下排列两张 3D 画面。

总页数控制在 11 页以内：背景 2 页、产品双模式 2 页、人物/情景 1 页、技术底座 2 页、体验旅程 2 页、Lux3D 与价值 2 页。

## 6. 视频插入点

- `0:20–0:35`：人物卡从轮椅使用者切换为夜间老年住户，再回到主 Demo 角色，建立“同一空间服务多种生活状态”。
- `1:35–1:52`：失败诊断卡右上角加入情景标签“白天 / 正常照明”。
- `2:30–2:45`：复测成功后快速切换夜间和应急预计算缩略图，展示实验室模式的组合能力。

视频主线仍保持一个稳定任务；多人物和多情景承担产品广度说明，真实运行路径与预计算展示分别标注。

## 7. 素材验收

- 每张人物卡包含称谓、任务、关键变量和表现方式。
- 每张情景卡包含环境条件、测试重点、任务和数据状态。
- 夜间和应急镜头保留文字标签，支持无障碍字幕和非颜色识别。
- 应急素材使用可复现的空间状态，烟雾/火焰等效果在能力未验证前标为概念素材。
- 现场主 Demo 的住户、任务、起点和情景固定；扩展人物与情景使用预计算结果或独立录屏。
