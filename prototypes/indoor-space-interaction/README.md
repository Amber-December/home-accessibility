# ACCESS · 室内通行实验室

浏览器端交互原型，只做产品前端的参考。分数和结论以 `src/ha/evaluator` 为准，原型里的判定不进视频和报告。原型的住户画像（含视障白杖）和任务是原型自带的演示设定，正式画像和任务见 `src/ha/resident/personas.yaml`。

## 启动

- 双击 `启动室内空间.bat`，或在本目录运行 `node server.cjs`。需要 Node.js 18 及以上，不需要 npm 安装、联网或构建。
- 服务只绑定 `127.0.0.1`，默认端口 8910。同一个应用已在运行时直接复用；端口被其他程序占用时自动尝试下一个端口。新启动的服务要保持终端开着。
- 也可以直接双击 `index.html` 用 `file://` 打开。示例场景能正常体验，但部分模型的配套文件会受浏览器本地文件限制，导入模型时用本地服务更稳。
- 两种方式都在本机解析模型，不会把模型传到远程服务器。

## 使用

1. 默认进入「任务驱动数字住户」和可编辑住宅。可切换到「自由探索」，场景可选办公空间、九展台展馆或上传的模型。
   - 视图：空间透视、细节近景、平面分析、跟随住户、自由步入。
   - 自由步入：WASD 移动，左键拖动转视角，E 开关附近的住宅门。手动探索会暂停任务，操作不计入任务报告。
   - 精细画质包含 SSAO、环境反射和柔和阴影。
2. 导入一个主模型，可同时多选配套的材质、贴图和 BIN。
   - 支持 OBJ+MTL、ASCII/二进制 STL、3DS、GLB/GLTF、FBX、DAE。
   - STL 和 3DS 默认 Z 向上，其余默认 Y 向上；DAE 用加载器转换后的轴向。导入设置里可以覆盖。
   - 模型单位默认米，毫米模型改成 mm 后点「重新导入」。
3. 地面自动取靠近模型底部的大型水平面，也可以填「地面距模型最低点」覆盖。
   - 识别到足够的地板时，只有地板区域可通行；没有地板时用模型的平面包围范围作虚拟地面。
   - 导入后检查平面尺寸、地板支撑和碰撞栅格。
4. 自由探索的行人是三种半径的圆盘（0.25 / 0.45 / 0.38 m），在各自身体尺度对应的最大连通区生成。
   - 运动由局部视野避障、人群分离、全局栅格寻路和连续分步碰撞共同控制。
   - 搜索范围内没有目的地时，行人去更远的目的地。所有行人共用同一张已知平面地图。
5. 添加或删除目的地，或改变人数、人群构成、栅格精度，会清空旅程统计。速度、视野和搜索距离实时生效。暂停时视图仍可操作；页面切到后台时暂停推进。
6. 导出 JSON（参数、指标、栅格、事件）或 CSV（全部栅格，可导入 GIS、Excel、Grasshopper）。坐标是居中后的 X / Z 米制坐标。
7. 目的地模式有「默认」「只使用自定义」「默认 + 自定义」三种。
   - 自定义目的地可在地面点选，也可输入名称和 X / Z 坐标。在默认模式下添加会自动切到混合模式。
   - 只使用自定义但还没有目的地时，行人原地等待。
   - 切换模式不删除自定义目的地；「恢复默认」重新启用全部默认目的地并保留自定义列表。
   - 同一模型改栅格精度时保留目的地，导入新模型时重建。
8. 点击有颜色的磕碰栅格，查看累计接触、障碍受阻、人际等待、原因、涉及的家具或墙体、人群、身体包络宽度和时间，选中位置有红框。点击事件列表也会定位并打开对应栅格。

## 指标含义

- **接触**：行人的一次移动尝试与障碍安全半径重叠。系统不允许穿透，每人每秒最多记一次。人际避让不算建筑接触。
- **受阻旅程**：目的地对当前身体半径不连通，或连续停滞超过 3.5 秒（人群拥堵也会触发）。每段旅程最多记一次，之后另选目的地。
- **磕碰热点**：障碍接触次数加障碍受阻次数，两项也可以分开显示。人际避让造成的等待单独统计，不进热点。
- **原因归属**：接触记录来自一次被碰撞系统挡住的移动，包含当时碰到的栅格和模型对象。受阻记录里的附近障碍只是定位线索，不等于实际接触面。门宽来自内置模型的标注；导入模型里未识别的网格显示网格名。
- **问题面积**：有事件的栅格面积。**每百米磕碰**：接触次数 ÷ 全体累计行走米数 × 100。颜色按本次最大值归一化，不能跨次比较。
- **到达率**：到达 ÷（到达 + 受阻旅程），进行中的旅程不计入。
- 统计都来自实际步进模拟。重置时用固定随机种子。事件列表保留最近 5000 条；每个栅格另存累计原因和最近 8 条详情。清空事件列表不删热点原因，清空热点会同时删掉该层的原因。行人轨迹默认关闭。

## 碰撞与适用范围

- 碰撞从真实三角面截取离地 0.08–1.80 m 的部分，保守投影到栅格。每个网格都参与碰撞，支持旋转和实例变换。
- 小于 2 m² 的封闭投影空腔会被填实，防止行人生成在空心家具里。小隔间也可能被填掉，要看碰撞栅格确认。
- 栅格误差会让窄门更早受阻，先提高精度再比较。统一人体高度表示不了可以俯身或钻入的空间，悬挑和桌底按保守处理。
- 只支持一个水平地面，不处理楼梯、坡道、落差和净高分类，也不做规范条文判定。
- 压缩的 GLTF（Draco / Meshopt / KTX2）要先转成未压缩版本。模型上限 180 MB、200 万三角面；栅格上限约 20 万格，大场景自动降低分辨率。外部纹理只从本次选择的本地文件读取。

## 任务驱动数字住户

- 画像：轮椅住户、助行器老人、视障白杖住户、上肢活动受限住户。宽度、包络长度、速度、水平和最高触达、归一化操作阻力阈值都可调。默认值是演示假设，不代表整类人群，也不是医疗或规范参数。
- 任务：入户到沙发、卧室到卫生间、取用冰箱、床椅转移、紧急疏散。每项任务独立重置起点和门状态。
- 导航：搜索位置和 8 个朝向，平移和转向都检查矩形扫掠，允许倒退。
- 开门：检查接近、触达、操作阻力、门扇扫掠、与其他门扇的冲突和退让位置。铰链处用有限的栅格留量近似。
- 白杖：假设住户熟悉布局，沿已知路径做局部三向扫描，记录探测距离、构件和停顿。
- 取冰箱检查接近位置、把手高度和触达距离；床椅转移检查床侧包络空间。这些是几何判定，不含人体动力学、抓握力学和照护能力评估；疏散任务不含烟火蔓延。
- 记录：碰撞尝试、路径失败、转向失败、触达失败、开门失败、转移失败、最小包络余量、任务耗时和动作轨迹。导航拒绝穿透时记为路径失败。余量按已执行路径、身体包络和门扇计算，完成率提高不代表每条路径的余量都变大。
- 修复：规则候选搜索，不调用大模型。候选包括移动床侧椅、茶几、洗手柜，替换低位把手冰箱，改门的开启方向或执手参数。每个候选都重新建模、栅格化并跑同一组任务，最多 6 轮，只保留评分改善的修改，没修好的任务继续显示失败。
- 对比：修改前后固定画像、任务、起点和精度。耗时改善只统计前后都成功的任务。报告可导出完整配置、动作、探测、问题、候选审计和两套场景参数，可以切换前后查看或还原。
- 商品替换用内置尺寸方案。任务、动作和修复只针对带床、门、冰箱语义的内置住宅；导入模型只做自由通行检测。

## 办公场景

办公场景的六间周边办公室都能从走廊进入：跨门洞的装饰灯带不参与碰撞，南侧会议室的显示屏靠背墙放置，寻路按真实圆盘和栅格方块判定。回归测试让步行、轮椅、助行器三种行人分别实际走进六个房间，共 18 个用例。

## 代码结构

- `index.html`、`style.css`、`digital-twin.css`：中文控制台、全屏三维底图、悬浮面板和数字孪生主题。
- `js/core.js`：不依赖 Three.js 的欧氏距离变换、圆形碰撞、连通分区、Dijkstra 寻路和栅格数据。
- `js/geometry.js`：世界坐标三角面提取、地面识别、人体高度裁剪、保守栅格化。
- `js/scene.js`、`js/office.js`：九展台展馆、办公空间、PBR 材质、ACES 色调、柔和阴影、栅格烘焙的接触阴影、玻璃隔断、实例化家具与行人、轨迹和热力。
- `js/rendering.js`、`js/avatars.js`：SSAO、环境反射、Gamma / FXAA，带关节的人物、轮椅和助行器。`js/vendor/postprocessing` 是 Three.js r128 官方示例（MIT，来源 <https://github.com/mrdoob/three.js/tree/r128/examples/js>）。
- `js/importers.js`：本地模型和配套资源解析，尺度、轴向、地面变换。
- `js/simulation.js`：行人状态、目的地选择、导航与避碰、事件和统计。
- `js/app.js`：状态绑定、导入流程、视图控制和导出。
- `js/home.js`：可编辑住宅、家具商品参数、可操作门、语义 ID。
- `js/resident-nav.js`、`js/resident-tasks.js`：朝向导航、身体扫掠、白杖扫描、任务动作评估和轨迹执行。
- `js/resident-repair.js`、`js/resident-workbench.js`：候选修复、重建复测、画像参数、前后对比和任务报告。
- `server.cjs`：无依赖的本地服务，只允许访问本应用和上级目录的 `js/vendor`。

## 测试

- 算法：`node tests/core.test.cjs`。启动器：`node tests/launcher.test.cjs`。
- 浏览器测试需要 Playwright（`NODE_PATH` 指向已安装的包）和已启动的本地服务：`node tests/browser.test.cjs`、`node tests/accessibility.test.cjs`、`node tests/formats.test.cjs`。
- 数字住户和房间入口回归：`node tests/resident-regression.test.cjs`。覆盖四种画像、白杖动作、全轨迹静态碰撞、固定起点的前后修复、报告导出、门动画、手动步入和六个办公房间的实际进入。
