HOW IT WORKS

一个空间，多种通行体验。

  1. 先试运行。 点击开始，在室内空间观察行人；切换细节近景查看人物与家具，或切换平面分析查看磕碰热点。
  2. 导入模型。 选择主模型及配套资源；米制默认，Rhino / STL 常用 Z 向上。单位或地面不对时，在导入设置中调整并重新应用。
  3. 设置目的地。 在默认、自定义、混合三种模式间切换。自定义支持点击地面或输入名称及 X / Z 坐标；恢复默认会保留自定义列表。修改目的地会重置旅程和统计。
  4. 比较身体尺度。 混合人群含步行、轮椅和辅助器使用者。身体碰撞为圆盘，活动高度为 0.08–1.80 m，视野控制局部避障，搜索范围控制随机目的地选择。全局栅格寻路帮助绕行。
  5. 理解热力。 磕碰热点只累计障碍接触与障碍受阻，不显示人流密度。点击彩色栅格查看涉及对象、身体宽度、原因及时间。人际等待单独记录；不可达目标的附近对象是定位线索，不代表实际接触面。

USDZ 模型。首次导入前请运行文件夹内的「安装USDZ支持.bat」，它会安装本机 OpenUSD 转换依赖。导入时会展开 USD 主层、引用、实例和世界变换，再转为浏览器可显示的 GLB；模型只在本机处理，不上传文件。

随机受伤救援。 在办公楼或住宅楼启动后，系统会让一名行人先正常行走，随后确定性随机触发脚踝扭伤；两名医生从入口进入，携带担架按净空和碰撞栅格前往伤员并返回入口。担架磕碰会进入事件与热力记录，伤员会保持躺姿显示。

灾害实验。启动火灾或地震时会自动切换到人群仿真模式。火灾显示确定性网格温度、烟气、燃料、火焰传播和危险路径；地震显示确定性地震动、结构损伤、倒塌事件和掉落碎片。它们是可复现的降阶模型，用于比较疏散与碰撞行为，不等同于 CFD、有限元结构动力学或刚体破碎求解；需要工程级验证时请使用 Isaac Sim / PhysX 或专业求解器。

自然语言人物与行程。 DIY 模式可以分别输入人物描述和一天行程，例如“使用助行器的老人，速度 0.5 米每秒”和“早上先去床边，然后去冰箱，最后到卫生间”。GPT-5.6 仅通过本地服务端代理读取当前场景实体并返回结构化参数；未配置 API 时自动使用本地关键词解析。密钥只放在本地服务进程的 OPENAI_API_KEY 环境变量中，不写入浏览器。

该工具借鉴 Quelea 的代理行为思路，不依赖 Grasshopper。自由探索使用圆盘通行，任务住宅另外实现朝向包络、转向扫掠和可操作门；两者均模拟单一水平地面，不分析楼梯、坡度或规范合规；悬挑和桌底按统一人体高度保守处理。无地板模型使用包围范围内的虚拟地面；小型封闭家具内腔会填实，碰撞栅格可直接检查。原展馆仅复用布局与视觉语言，不共享其城市分析。数字住户支持四类可调画像和五项住宅任务；修复 Agent 为规则候选重建复测，商品仅为内置尺寸方案。任务模式支持内置住宅、办公场景和导入模型按目的地执行。点击场景家具后会自动识别名称和类别，从本机模型目录展示相似模型缩略图；点击卡片即可替换。带关节元数据的模型会按旋转轴、滑轨行程或 GLB 动画驱动，人物靠近时自动开合，并在状态气泡中显示操作反馈。没有语义名称或关节元数据的导入网格只能按名称、碰撞元数据和包围盒识别，无法保证视觉级家具分类。

GLTF 的 Draco / Meshopt / KTX2 压缩资源需先转为未压缩模型；未导出网格的 Rhino 曲面需先在 Rhino 中生成渲染网格再保存。模型数据仅在浏览器内解析。
